**Paketler:**
- `tailwindcss @tailwindcss/vite` — Tailwind v4 (CSS-first, config dosyası yok)
- `class-variance-authority clsx tailwind-merge` — shadcn/ui utilities
- `@radix-ui/*` — 10 primitive (tabs, select, dialog, tooltip, progress, avatar, label, separator, slot, dropdown-menu)

**Altyapı:**
- `vite.config.ts` — `@tailwindcss/vite` plugin eklendi
- `app.css` — `@import "tailwindcss"` + `@theme` bloğunda fm-* token → shadcn CSS variable mapping
- `inertia/lib/utils.ts` — `cn()` utility (clsx + tailwind-merge)

**Yeni backend:**
- `app/controllers/profile_controller.ts` — GET/POST /panel/profile (profil okuma & güncelleme)
- `app/controllers/orders_controller.ts` — GET /panel/orders (tamamlanan/iptal siparişler)
- `app/controllers/earnings_controller.ts` — GET /panel/earnings (ödeme talimatları + finansal özet)
- `app/validators/panel.ts` — `profileUpdateValidator` eklendi
- `start/routes.ts` — 4 yeni rota: orders, earnings, profile show/update

**Yeni frontend sayfalar:**

- `inertia/pages/panel/earnings.tsx` — Kazanç özeti (bu ay / bekleyen / ödenen / toplam), ödeme tablosu

**Güncellenen dosyalar:**
